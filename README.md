# PCVK — Pengolahan Citra dan Video Komputer

Notebook praktikum **Pengolahan Citra dan Video Komputer (PCVK)**,
dikerjakan di **Google Colab** memakai OpenCV, NumPy, dan scikit-image.

## Isi Praktikum

| File | Topik |
|------|-------|
| `P2_Week2_09.ipynb` | Praktikum minggu 2 — dasar pengolahan citra |
| `P3_Week3_09.ipynb` | Praktikum minggu 3 — citra negatif dan manipulasi warna |
| `Week5_Histogram_Dithering.ipynb` | Minggu 5 — histogram dan dithering |
| `latihan_integerasi.ipynb` | Latihan integrasi materi |

Tiap notebook diakhiri **Pertanyaan Praktikum** beserta jawabannya.

## Library yang Dipakai

- OpenCV (cv2)
- NumPy
- Matplotlib
- Pillow (PIL)
- scikit-image
- pandas

## Cara Menjalankan

Buka lewat badge **Open in Colab** di baris pertama tiap notebook,
atau jalankan lokal:

```bash
pip install jupyter opencv-python numpy matplotlib pillow scikit-image pandas
jupyter notebook
```

Beberapa notebook memuat gambar dari Google Drive, jadi saat dibuka
di Colab jangan lupa mount Drive dulu.
